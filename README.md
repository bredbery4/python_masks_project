# Проект: Маскировка и обработка банковских данных

## Описание
Этот проект предназначен для работы с данными банковских транзакций. Он включает в себя инструменты для маскировки номеров карт и счетов, преобразования форматов дат, а также функции для фильтрации и сортировки списков операций.

Проект разработан с использованием современных стандартов Python: аннотаций типов, линтеров и управления зависимостями через Poetry.

## Основной функционал

### 1. Модуль `processing.py` (Обработка данных)
* **filter_by_state**: Фильтрует список транзакций по заданному статусу (например, `EXECUTED`, `CANCELED`).
* **sort_by_date**: Сортирует список транзакций по дате. По умолчанию сортировка идет от новых к старым.

### 2. Модуль `widget.py` (Универсальные инструменты)
* **mask_account_card**: Автоматически определяет тип (карта или счет) и накладывает нужную маску на номер.
* **get_date**: Преобразует системную дату формата ISO (например, `2024-03-11T...`) в формат `ДД.ММ.ГГГГ`.

### 3. Модуль `masks.py` (Базовая маскировка)
* **get_mask_card_number**: Маскирует номер карты (видны первые 6 и последние 4 цифры).
* **get_mask_account**: Маскирует номер счета (видны только последние 4 цифры).

### 4. Модуль `generators.py` (Генераторы данных)
* **filter_by_currency**: Фильтрует итератор транзакций по заданной валюте (например, USD, RUB).
* **transaction_descriptions**: Поочередно возвращает текстовое описание для каждой транзакции.
* **card_number_generator**: Генерирует номера банковских карт в заданном диапазоне.
